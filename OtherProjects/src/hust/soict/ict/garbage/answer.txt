Question: If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this?
No, because the constructor with the same signature has already been defined.

Question:
● After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two
objects still remain?
● After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is
the title of the JungleDVD changed?
- After the call of swap method, the title of the objects still remain because the passing arguments are just copies of reference the the real objects, and local variables declared inside method swap are new references pointing to the same objects. So swapping these references does not affect the original references inside method main
- After the call of changeTitle method, the title of jungleDVD changes because the attribute title inside the object jungleDVD has been changed through the new reference in method changeTitle. After the call, the new reference disappears but the real object has been modified
